# 🚀 SpendSmart — Personal Finance Assistant

SpendSmart is a premium personal finance application designed to help you track expenses, analyze spending habits using AI, and manage your wealth effectively.

## ✨ Features
- **📊 Real-time Dashboard**: Track your current balance, budget utilization, and daily spending.
- **✨ AI Insights (Gemini)**: Personalized financial strategies generated by Google Gemini AI based on your actual spending.
- **💳 Credit Card Tracker**: Monitor multiple credit cards, track utilization, and log payments/charges.
- **🏦 Loan & Savings Tracker**: Track your loans, EMIs, and monthly auto-savings.
- **📅 Monthly Reports**: Comprehensive monthly breakdowns with PDF export functionality.
- **🔄 Recurring Transactions**: Manage subscriptions and automated bills easily.
- **📱 PWA — Installable on Mobile**: Install SpendSmart as a native-like app on Android & iPhone.

## 🚀 Deployment Guide

### 1. Backend (on Render.com)
1. Create a new **Web Service** on [Render](https://render.com) and connect this repository.
2. Set **Root Directory** to `server`.
3. **Build Command**: `npm install` | **Start Command**: `npm start`
4. Add these **Environment Variables**:
   - `SUPABASE_URL`: Your Supabase project URL
   - `SUPABASE_SECRET`: Your Supabase secret key
   - `JWT_SECRET`: A random long string for security
   - `GEMINI_API_KEY`: Your key from [AI Studio](https://aistudio.google.com/)
   - `CLIENT_URL`: The URL of your Vercel frontend (once deployed)
   - `PORT`: `5001`

### 2. Frontend (on Vercel.com)
1. Import this repo on [Vercel](https://vercel.com).
2. Set **Root Directory** to `client`.
3. Add this **Environment Variable**:
   - `VITE_API_URL`: Your Render backend URL (e.g., `https://spendsmart-api.onrender.com`)
4. Deploy — everything else is pre-configured in `vercel.json`.

### 3. Link them together
After both are deployed, go back to Render → Environment → set `CLIENT_URL` to your Vercel URL.

## 📱 Install on Phone (PWA)
- **Android**: Open in Chrome → tap **"Install SpendSmart"** banner
- **iPhone**: Open in Safari → Share → **"Add to Home Screen"**

## 🛠️ Local Development

1. **Clone the repo**: `git clone https://github.com/varshith125/finance-dashboard-ui`
2. **Start backend**: `cd server && npm install && npm run dev`
3. **Start frontend**: `cd client && npm install && npm run dev`
